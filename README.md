# Sinquerim Fort / Goa

A single-page Astro + Tailwind CSS + TypeScript visitor guide for Sinquerim Fort (Sinquerim Beach Bastion), Candolim, Goa.

## Commands

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm build
```

Set `PUBLIC_SITE_URL` only when the production domain is known. It is the sole site URL configuration; when unset, the project builds without absolute canonical URLs and does not generate a sitemap.
